PHẦN 1: ĐIỀU KIỆN ĐƯỢC THI (ĐIỀU KIỆN DỰ THI KỲ THI CUỐI KỲ / PE / FE)
==================================================
1. Quy định về chuyên cần (Điểm danh):
   - Sinh viên KHÔNG ĐƯỢC VẮNG QUÁ 20% tổng số buổi học của môn học (nghĩa là tỷ lệ có mặt tối thiểu phải đạt từ 80% trở lên).
   - Nếu sinh viên nghỉ học quá 20% tổng số buổi (dù có phép hay không phép), sinh viên sẽ bị CẤM THI (Status: Attendance Fail), bị tính điểm 0 và bắt buộc phải đăng ký học lại môn đó.
2. Điều kiện điểm thành phần (Điểm quá trình):
   - Hoàn thành đầy đủ các đầu điểm kiểm tra quá trình, bài thực hành (Lab), bài tập lớn (Assignment / Progress Test).
   - Điểm trung bình các thành phần quá trình phải đạt điều kiện tối thiểu theo quy định của từng đề cương môn học (thường không có điểm thành phần nào bị 0 điểm).
3. Nghĩa vụ học phí và thủ tục:
   - Sinh viên phải hoàn thành đóng học phí đầy đủ trước thời hạn quy định của học kỳ. Sinh viên nợ học phí sẽ bị rút tên khỏi danh sách thi.

   - CẤM mang vào phòng thi các thiết bị truyền tin (thu, phát sóng, ghi âm, ghi hình) hoặc chứa dữ liệu để gian lận. Nếu mang theo phải TẮT NGUỒN hoàn toàn và để ở nơi quy định.
   - Cấm sử dụng tài khoản của người khác hoặc cho người khác dùng tài khoản của mình để đăng nhập hệ thống thi.

   - Trong trường hợp môn thi cho phép sử dụng AI, nếu phần bài làm do AI tham gia tạo ra mà sinh viên KHÔNG GHI RÕ thì sẽ bị HỦY BỎ KẾT QUẢ BÀI THI (0 điểm).
   - Các môn không cho phép: Cấm tuyệt đối mọi hình thức AI (ChatGPT, Copilot, Gemini...).
5. Quy định phúc khảo điểm thi:
   - Thời hạn nộp đơn phúc khảo: Trong vòng 3 NGÀY LÀM VIỆC kể từ ngày công bố điểm thi.
   - Thời hạn nhà trường trả lời: Chậm nhất 5 NGÀY LÀM VIỆC kể từ ngày hết hạn nhận đơn.
   - Sinh viên được làm đơn phúc khảo tối đa 2 LẦN cho mỗi bài thi. Khoản tiền xử lý đơn sẽ được hoàn trả nếu điểm thi được điều chỉnh sau phúc khảo.
6. Hình thức kỷ luật vi phạm:
   - Cảnh cáo: Bị trừ 50% số điểm bài thi đó (áp dụng khi nhìn bài, trao đổi lần 1).
   - Đình chỉ thi: Bị điểm 0 toàn bộ môn thi đó, phải rời phòng thi ngay lập tức.
   - Đưa đề thi ra ngoài hoặc đưa bài giải vào: Đình chỉ thi, đình chỉ học 1 học kỳ, nếu tái phạm sẽ Buộc thôi học hoặc chuyển cơ quan Công an xử lý.

   - Quy ước đặt tên project bắt buộc: <ClassName>_<StudentID>_<ProjectCode>_PE
     (Ví dụ: SE1801_SE123456_RMS_PE).
   - Kiểu project: Spring Boot, loại đóng gói (package type) là 'war' (hoặc jar theo đề) chạy trên JDK 21.
   - Công nghệ bắt buộc: Spring Boot (phiên bản 3.4.x / 3.5.x), Spring Data JPA, Spring MVC 6 và Thymeleaf.
   - LƯU Ý ĐẶC BIỆT CẤM THƯ VIỆN NGOÀI: TUYỆT ĐỐI KHÔNG ĐƯỢC PHÉP SỬ DỤNG CÁC THƯ VIỆN KHÁC, ĐẶC BIỆT LÀ LOMBOK (Do not allow use other libraries e.g. lombok). Sử dụng lombok hoặc thư viện ngoài danh sách quy định sẽ bị 0 ĐIỂM.
   - Trình điều khiển CSDL: Dùng MS SQL Server Driver có sẵn trong project Spring Boot cho MS SQL Server 2016 trở lên.
3. Quy chuẩn cấu trúc Package (MVC & Layer Pattern) bắt buộc tuân thủ:
   Toàn bộ mã nguồn Java phải đặt trong các package theo cấu trúc sau (thay <studentId> bằng mã số sinh viên viết chữ thường):
   - com.<studentId>.mvc.entity          : Chứa các Entity class ánh xạ bảng CSDL.
   - com.<studentId>.mvc.repository      : Chứa các Repository Interface (kế thừa JpaRepository).
   - com.<studentId>.mvc.service         : Chứa các Service Interface khai báo nghiệp vụ.
   - com.<studentId>.mvc.service.impl    : Chứa các Service Implementation class cài đặt logic.
   - com.<studentId>.mvc.controller      : Chứa các Controller class điều hướng và xử lý request.
   - com.<studentId>.mvc.dto             : Chứa các Data Transfer Object (DTO) truyền dữ liệu.
   - com.<studentId>.mvc                 : Chứa file cấu hình (Configuration) và Application main class.
   (Lưu ý: Tên class và thuộc tính class phải đúng theo yêu cầu đề bài; vi phạm cấu trúc package sẽ bị trừ điểm hoặc không được chấm bài).
4. Cấu hình bắt buộc trong file 'application.properties':
   - Database name: Tên theo đề thi (ví dụ: HSF302_2025_PE hoặc HSF302_2026_PE).
   - Server name & Port: localhost:1433
   - spring.datasource.username: sa
   - spring.datasource.password: sa
   - CSDL phải được thiết lập chế độ xác thực: SQL Server and Windows Authentication mode (SQL Server authentication).
   - server.servlet.context-path: /
   - server.port: 8080
   - spring.jpa.hibernate.ddl-auto: none
   - Path for the application page in controller: /
   - URL truy cập trang chủ ứng dụng bắt buộc là: http://localhost:8080/
5. Yêu cầu CSDL (Database):
   - Sinh viên chạy script file .sql được cấp kèm theo đề để tạo bảng và dữ liệu mẫu.
   - Tên bảng và tên trường (table name, field name) trong CSDL và Entity PHẢI CHÍNH XÁC 100% theo mô tả đề thi. Nếu vi phạm, bài làm sẽ bị CHẤM ĐIỂM 0.
6. Hướng dẫn nộp bài (Submit Guideline) qua hệ thống EOS:
   - Bước quan trọng trước khi nén zip: Sinh viên BẮT BUỘC phải chạy lệnh 'mvn clean' trong thư mục project để xóa toàn bộ các file class đã compile trong thư mục 'target/' nhằm giảm dung lượng.
   - Sau đó nén cả thư mục project thành 1 file .zip (đảm bảo dung lượng nhẹ).
   - Nộp file .zip lên phần mềm thi EOS theo đúng hướng dẫn của giám thị.
